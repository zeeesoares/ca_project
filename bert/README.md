# Bert - Testing

## How to run?

- Create a virtual environment : `python3 -m venv env-bert` 
- Install libs from _requirements.txt_ : `pip install -r requirements.txt`
- Run :\) : `python3 train.py`

## For us:

- Go to the folder `bert_checkpoints` during or in the end of the training and see the `checkpointing_log.txt`
